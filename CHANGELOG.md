# Changelog

## 1.2.1

- First-draft QA distinguishes quiet motion from held frames, reports visual issue intervals, and attempts one repair before failing.
- Failed first drafts offer a retry in Project Setup, and fallback audio is limited before export.

## 1.2.0

- Project Setup can make a first editorial draft from a folder, raw footage, and references. It includes input review and uses the project format, style and learned preferences.
- Draft Review records input findings or access blockers. Source previews remain available as historical versions.

## 1.1.1

- Tightened the responsive layout for narrow phones, tablets, and short landscape viewports. Navigation wraps, controls stay within their panels, and comparison and review previews adapt to the available space.

## 1.1.0

- Redesigned the KAT Studio interface with a responsive style gallery, search, category filters, visual examples, comparison and preset handoff.
- Bundled 30 Creator Pack presets and two versions of the GLK style. Existing style versions are preserved on startup.
- Added automatic folder classification, project-format intake previews, style previews in project setup, and side-by-side draft playback.
- Added persistent project and client learning, notes and approvals, and shared editorial context for assisted edits.
- Added CLI context retrieval and verified draft registration. Validation checks style, sources, format, stream health, audio and required closing-card footage.
- Documented reusable caption, pacing, B-roll, transition and delivery checks and retained portable initialization, backup, recovery and release verification.

## 1.0.0

- Initial portable KAT Studio checkout, launcher, installer and Codex skill.
